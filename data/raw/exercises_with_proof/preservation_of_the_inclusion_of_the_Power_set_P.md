$A \subseteq B$ if and only if $P(A) \subseteq P(B)$

Proof: $\Rightarrow)$ if $x \in P(A)$, then $x \subseteq A$.Since, by hypotesis, $A \subseteq B$, then we get, using the transitivity of inclusion, that $x \subseteq B$; this means, $x \in P(B)$.

$\Leftarrow)$ if $x \in A$, then $\{x\} \subseteq A$, which implies $\{x\} \in P(A)$.By hypotesis, we have $\{x\} \in P(B)$;from here, $\{x\} \subseteq B$ and this implies that $ x \in B$
