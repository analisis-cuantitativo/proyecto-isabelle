- We need: `inj f ↔ ∃g : B → A. g ∘ f = id`

In Isabelle, this would be:
```
theorem injective_iff_left_inverse (f : 'a → 'b) :
  "inj f ↔ (∃g : 'b → 'a. (g ∘ f) = id)"
```

For the proof:
- Forward direction (→): If `f` is injective, we need to construct a left inverse `g`.
  - For each `b ∈ B`, if `b` is in the image of `f`, pick the unique `a` with `f(a) = b`
  - Otherwise, pick an arbitrary element from `A`

- Backward direction (←): If such a `g` exists, then `f` is injective.
  - If `f(a) = f(a')`, then `a = g(f(a)) = g(f(a')) = a'`
