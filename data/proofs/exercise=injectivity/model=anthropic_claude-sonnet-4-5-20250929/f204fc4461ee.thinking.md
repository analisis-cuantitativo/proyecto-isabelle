This is a classic result about injective functions and left inverses. Let me formalize this in Isabelle.

The statement is: f is injective if and only if there exists g such that g ∘ f = id_A.

In Isabelle, I need to:
1. Define what it means for f to be injective
2. State that there exists g : B → A such that g ∘ f = id on A
3. Prove both directions

Let me write the Isabelle theory:

```isabelle
theory InjectiveLeftInverse
  imports Main
begin

theorem injective_iff_left_inverse:
  fixes f :: "'a ⇒ 'b"
  shows "inj f ⟷ (∃g :: 'b ⇒ 'a. ∀x. g (f x) = x)"
proof
  assume "inj f"
  then show "∃g :: 'b ⇒ 'a. ∀x. g (f x) = x"
  proof -
    obtain g where "∀x. g (f x) = x"
      using `inj f` by (metis inv_into_f_f)
    thus ?thesis by auto
  qed
next
  assume "∃g :: 'b ⇒ 'a. ∀x. g (f x) = x"
  then obtain g where g_prop: "∀x. g (f x) = x" by auto
  show "inj f"
  proof (rule injI)
    fix x y
    assume "f x = f y"
    then have "g (f x) = g (f y)" by simp
    with g_prop show "x = y" by simp
  qed
qed

end
```
