2. This is a classic result in set theory/category theory.

The two directions:
- (→) If f is injective, then there exists g: B → A such that g ∘ f = id_A
- (←) If there exists g: B → A such that g ∘ f = id_A, then f is injective

For the forward direction, we need to construct g. For any b in B:
- If b is in the image of f, let g(b) = the unique a such that f(a) = b (unique because f is injective)
- If b is not in the image of f, we can map it to any arbitrary element of A (requires A to be non-empty)

For the backward direction: if g ∘ f = id_A, then for any a1, a2 in A:
- If f(a1) = f(a2), then g(f(a1)) = g(f(a2))
- But g(f(a1)) = (g ∘ f)(a1) = id_A(a1) = a1
- Similarly g(f(a2)) = a2
- So a1 = a2, proving f is injective
