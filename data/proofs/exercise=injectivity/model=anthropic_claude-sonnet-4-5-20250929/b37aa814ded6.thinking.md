1. We have a function f: A → B
2. We need to prove: f is injective ↔ ∃g: B → A. g ∘ f = id_A

This is a classic result in set theory/category theory.

For the forward direction (injective → exists left inverse):
- If f is injective, we need to construct g: B → A such that g(f(a)) = a for all a ∈ A
- For elements in the image of f, we can define g to map them back to their unique preimage
- For elements not in the image, we need to pick some arbitrary element of A (requires A to be nonempty)

For the backward direction (exists left inverse → injective):
- If g ∘ f = id_A, then for all a₁, a₂ ∈ A: if f(a₁) = f(a₂), then a₁ = g(f(a₁)) = g(f(a₂)) = a₂
- So f is injective
