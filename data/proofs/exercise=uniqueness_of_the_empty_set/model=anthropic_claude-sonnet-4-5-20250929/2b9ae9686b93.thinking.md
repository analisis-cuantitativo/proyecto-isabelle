The uniqueness of the empty set is a fundamental result in set theory. It states that there is only one set with no elements. In other words, if two sets are both empty (have no elements), then they are equal.

Formally, this can be stated as:
For all sets A and B, if A has no elements and B has no elements, then A = B.

Alternatively: For all sets A, if A has no elements, then A = {} (the empty set).

In Isabelle/HOL, we can express this as:
- If `∀x. x ∉ A` and `∀x. x ∉ B`, then `A = B`
- Or: If `∀x. x ∉ A`, then `A = {}`

The proof follows from the axiom of extensionality: two sets are equal if and only if they have the same elements.
